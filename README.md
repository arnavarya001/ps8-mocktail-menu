
# PS8 - Mocktail Menu

## Project
A React website for exploring non-alcoholic drinks and their recipes.

## API Used
TheCocktailDB

https://www.thecocktaildb.com/api/json/v1/1/filter.php?a=Non_Alcoholic

## Routes
- / - Home page
- /drinks - Drinks list and search
- /drinks/:id - Drink recipe details
- * - Page not found

## Features
- View mocktails
- Search drinks by name
- View ingredients and instructions
- React Router navigation
